Network device flags (IFF_*). Mirrors IFF_* defines in <uapi/linux/if.h>.

rtnetlink link attribute types (IFLA_*). Mirrors IFLA_* defines in <uapi/linux/if_link.h>.

rtnetlink message header layouts. Layout descriptors (per-field offset/size/signedness) generated from <uapi/linux/rtnetlink.h>; consume via require("struct").
