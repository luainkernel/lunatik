    linux.nfModule

    Linux kernel constants exposed under linux.nf.

    Values are populated at build time from the kernel headers.

    Usage

    local nf = require("linux.nf")

    Tables

    action Netfilter hook verdicts.
    arp Netfilter hook positions in the ARP family.
    br Netfilter hook positions in the BRIDGE family.
    br.pri Netfilter hook priorities in the BRIDGE family.
    ct.dir Conntrack tuple directions.
    ct.info Conntrack per-packet states (IS_REPLY is the reply-direction threshold, not a state).
    ct.status Conntrack status flags (NAT_CLASH is the in-kernel meaning of the obsolete UNTRACKED bit).
    ct.tcp TCP conntrack states (SYN_SENT2 is the live name for the obsolete LISTEN).
    inet Netfilter hook positions in the INET family.
    ip.pri Netfilter hook priorities in the IP family.
    netdev Netfilter hook positions in the NETDEV family.
    proto Netfilter protocol families.

    Tables in detail

    action
    Netfilter hook verdicts. Mirrors NF_* defines in <uapi/linux/netfilter.h>. Keys are the kernel names with the prefix stripped: NF_<NAME> is linux.nf.action.<NAME>.
    arp
    Netfilter hook positions in the ARP family. Mirrors NF_ARP_* defines in <uapi/linux/netfilter_arp.h>. Keys are the kernel names with the prefix stripped: NF_ARP_<NAME> is linux.nf.arp.<NAME>.
    br
    Netfilter hook positions in the BRIDGE family. Mirrors NF_BR_* defines in <uapi/linux/netfilter_bridge.h>. Keys are the kernel names with the prefix stripped: NF_BR_<NAME> is linux.nf.br.<NAME>.
    br.pri
    Netfilter hook priorities in the BRIDGE family. Mirrors NF_BR_PRI_* defines in <uapi/linux/netfilter_bridge.h>. Keys are the kernel names with the prefix stripped: NF_BR_PRI_<NAME> is linux.nf.br.pri.<NAME>.
    ct.dir
    Conntrack tuple directions. Mirrors IP_CT_DIR_* defines in <uapi/linux/netfilter/nf_conntrack_tuple_common.h>. Keys are the kernel names with the prefix stripped: IP_CT_DIR_<NAME> is linux.nf.ct.dir.<NAME>.
    ct.info
    Conntrack per-packet states (IS_REPLY is the reply-direction threshold, not a state). Mirrors IP_CT_* defines in <uapi/linux/netfilter/nf_conntrack_common.h>. Keys are the kernel names with the prefix stripped: IP_CT_<NAME> is linux.nf.ct.info.<NAME>.
    ct.status
    Conntrack status flags (NAT_CLASH is the in-kernel meaning of the obsolete UNTRACKED bit). Mirrors IPS_* defines in <uapi/linux/netfilter/nf_conntrack_common.h>. Keys are the kernel names with the prefix stripped: IPS_<NAME> is linux.nf.ct.status.<NAME>.
    ct.tcp
    TCP conntrack states (SYN_SENT2 is the live name for the obsolete LISTEN). Mirrors TCP_CONNTRACK_* defines in <uapi/linux/netfilter/nf_conntrack_tcp.h>. Keys are the kernel names with the prefix stripped: TCP_CONNTRACK_<NAME> is linux.nf.ct.tcp.<NAME>.
    inet
    Netfilter hook positions in the INET family. Mirrors NF_INET_* defines in <uapi/linux/netfilter.h>. Keys are the kernel names with the prefix stripped: NF_INET_<NAME> is linux.nf.inet.<NAME>.
    ip.pri
    Netfilter hook priorities in the IP family. Mirrors NF_IP_PRI_* defines in <uapi/linux/netfilter_ipv4.h>. Keys are the kernel names with the prefix stripped: NF_IP_PRI_<NAME> is linux.nf.ip.pri.<NAME>.
    netdev
    Netfilter hook positions in the NETDEV family. Mirrors NF_NETDEV_* defines in <uapi/linux/netfilter.h>. Keys are the kernel names with the prefix stripped: NF_NETDEV_<NAME> is linux.nf.netdev.<NAME>.
    proto
    Netfilter protocol families. Mirrors NFPROTO_* defines in <uapi/linux/netfilter.h>. Keys are the kernel names with the prefix stripped: NFPROTO_<NAME> is linux.nf.proto.<NAME>.
