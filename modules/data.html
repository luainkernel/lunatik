    data

    new (size[, mode]) Allocates a buffer of size bytes, zeroed.

    Class data in detail

    Represents a byte buffer. This is a userdata object returned by data.new() and by the modules that expose kernel memory (as skb:data()), read and written through the getuint/setuint accessors below.

    data in detail

    new (size[, mode])
    Allocates a buffer of size bytes, zeroed.

    Parameters

    • size integer number of bytes, from 1 up to INT_MAX.
    • mode string "shared" (default) or "single"; a "single" buffer cannot be passed to another runtime. (optional)

    Returns

      data

    Raises

    if out of bounds, the mode is invalid, or allocation fails
