Module netlink.rt

rtnetlink interface for routes, links and addresses.

A netlink.session specialization over the NETLINK_ROUTE protocol: create an instance with netlink.rt() and call its methods; the underlying socket is closed by close() (or the to-be-closed __close). All methods block and require a sleepable runtime.

See also:

    netlink.session
