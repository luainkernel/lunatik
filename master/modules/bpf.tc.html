    Lua API · Packets and eBPF

    bpf.tcModule

    Declares a TC program in a program file.

    The body of a program file runs on the host under lunatik bpf; the function it hands to program is compiled to eBPF and runs in the kernel on each packet the device receives, or sends. It takes one argument, the context, and returns a verdict, a value of linux.tc.action, of which the kernel reads the low 32 bits: OK, SHOT and REDIRECT act, and any other value reads as UNSPEC, which decides nothing. Where Lua would raise, at a read past the packet or a division by 0, the program stops and returns its default verdict.

    The program’s argument is spelled as the kernel’s skb object: #skb is the packet’s length, skb:ifindex() its device’s index, skb:hash() its flow hash and skb:priority() its priority, which skb:priority(v) sets to a value from 0 up to U32_MAX, returning it. A value outside them is refused where the compiler holds it, and stops the program where the program computes it. Any other method is refused, skb:mark() among them. skb.data/skb.data_end are the packet’s bounds rather than numbers, and skb:data() is the packet from skb->data, read as ctx:packet() is in bpf.xdp; a layer is refused, and an skb that is not linear, where the kernel’s skb:data() raises in a tc callback, stops the program.

    Usage

    local tc     = require("bpf.tc")
local action = require("linux.tc").action

return tc.program(function(skb)
    if #skb > 1500 then
        skb:priority(1)
    end
    return action.OK
end, {egress = true})

    Functions in detail

    bpf.tc.program (fn[, opts])
    Declares fn as a TC program.

    Parameters

    • fn function the program; it takes the context and returns a verdict.
    • opts table egress, which attaches the program on the way out rather than in, default, the verdict the program returns where it stops, where Lua would raise (linux.tc.action.OK), and name, what the program is called in the object, cut to the fifteen characters BPF_OBJ_NAME_LEN leaves and made unique against the names already taken. (optional)

    Returns

      table the declared program

    Raises

    tc.program takes a Lua function, or <file>:<line>: tc.program's default verdict is not an integer, the line where fn is defined
